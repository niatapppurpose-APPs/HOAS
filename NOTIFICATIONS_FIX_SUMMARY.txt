## 🚀 Quick Start - What You Need to Do

### **For New Fresh Installation**:
1. Deploy the updated code ✅ (Already done)
2. New users will automatically get preferences on login
3. Done! Everything works

### **For Existing Users** (One-Time Fix):
1. Open browser DevTools → Console (on any page while logged in)
2. Run this script:
```javascript
const { fixAllUsersNotificationPrefs } = await import('./src/maintenance/fixNotificationPrefs.js');
const result = await fixAllUsersNotificationPrefs();
console.log(result); // Shows how many users were fixed
```
3. Done! All existing users now have notifications enabled

### **Test It Works**:
```javascript
// In browser console:
// 1. Test sound:
const { playNotificationSound } = await import('./src/firebase/notificationService.js');
playNotificationSound('announcement'); // Should hear 3-note sound

// 2. Check preferences initialized:
const { getNotificationStats } = await import('./src/utils/notificationPrefsManager.js');
const uid = firebase.auth().currentUser.uid;
const stats = await getNotificationStats(uid);
console.log('✅ Notifications enabled:', stats.notificationsEnabled);
```

## 💡 Pro Tips

1. **To test sound manually:**
   ```javascript
   const { playNotificationSound } = await import('./src/firebase/notificationService.js');
   playNotificationSound('urgent');  // Try: 'urgent', 'success', 'announcement', 'normal'
   ```

2. **To check if a user has notifications enabled:**
   ```javascript
   const { getNotificationStats } = await import('./src/utils/notificationPrefsManager.js');
   const stats = await getNotificationStats('any-user-id');
   console.log(stats.notificationsEnabled); // true or false
   ```

3. **To reset a user's preferences to defaults:**
   ```javascript
   const { resetNotificationPrefs } = await import('./src/utils/notificationPrefsManager.js');
   await resetNotificationPrefs('user-id');
   ```

4. **To disable just sound for all future notifications (keep other notifications):**
   ```javascript
   const { disableNotifPref } = await import('./src/utils/notificationPrefsManager.js');
   await disableNotifPref('user-id', 'soundAlerts');
   ```

5. **Check Announcements Data**: Verify has `managementId` and `status`
