================================================================================
CLOUD FUNCTION SCHEDULER
================================================================================

FREQUENCY: Every 5 minutes
TIMEZONE: UTC (server-side)
ESTIMATED COST: ~260 invocations/month (~4 cents/month)

WHAT IT DOES:
  1. Checks for one-time scheduled announcements due to be published
  2. Checks for recurring announcements with next occurrence due
  3. Gets list of students to notify (by managementId/hostelBlock)
  4. Creates Firestore notification docs (max 400 per batch)
  5. Updates announcement status and tracking fields
  6. NotificationContext auto-picks up notification docs

================================================================================
NEW FIRESTORE FIELDS
================================================================================

ANNOUNCEMENTS COLLECTION - New Fields:
  • status (string): 'published'|'scheduled'|'recurring'|'draft'|'expired'
  • isImmediate (boolean): Was posted immediately?
  • scheduledTime (Timestamp): When to publish (if scheduled)
  • isSent (boolean): Has been published?
  • sentAt (Timestamp): When actually published
  • isRecurring (boolean): Is recurring?
  • recurrencePattern (object): Frequency + timing config
  • recurrenceEndDate (Timestamp): When to stop recurring
  • lastPublishedAt (Timestamp): Last publish time (for recurring)

RECURRENCE PATTERN STRUCTURE:
  {
    type: 'daily'|'weekly'|'monthly',
    time: '09:00',              // HH:MM format
    daysOfWeek: [1,3,5],       // 0-6 (Sun-Sat), for weekly
    dayOfMonth: 15             // 1-31, for monthly
  }

SYSTEM SETTINGS - New Config:
  Location: systemSettings/global in Firestore

  features.announcements: {
    enabled: true,
    schedulingEnabled: true,
    emailNotifications: false,  // (future)
    smsNotifications: false,    // (future)
    minAdvanceMinutes: 5,
    maxScheduledPerWarden: 20
  }

QUICK REFERENCE
================================================================================

ANNOUNCEMENT STATES:
  published: Visible immediately, isSent=true
  scheduled: Queued, published by scheduler at scheduledTime
  recurring: Repeats per pattern, auto-publishes each time
  draft: Saved but not published, hidden from students
  expired: Recurrence ended, not visible to students

WARDEN WORKFLOW:
  1. Go to Warden - Announcements
  2. Click 'New Post'
  3. Fill title + content
  4. Choose: Post Now / Schedule Later / Repeat
  5. Set priority + options
  6. Submit - Saved and queued

STUDENT WORKFLOW:
  1. Notification bell shows badge when announcement published
  2. Click bell - See NotificationPanel
  3. Click announcement - View details

SUPPORT / TROUBLESHOOTING
================================================================================

Q: Announcements not appearing?
A: Check:
   - Firestore systemSettings/global exists with correct config
   - announcement.managementId matches student.managementId
   - student.status = 'approved'
   - Cloud Function logs for errors

Q: Scheduler not running?
A: Check:
   - Cloud Functions deployed successfully
   - Check Cloud Scheduler in Google Cloud Console
   - Verify publishScheduledAnnouncements exists
   - Check function logs

Q: Timezone issues?
A: Browser converts scheduler's UTC time to local.
   If issues: Add timezone field to announcement doc

Q: Duplicate notifications?
A: Should not happen - isSent flag prevents re-publishing
   Check Cloud Function logs
